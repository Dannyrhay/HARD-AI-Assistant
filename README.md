# HARD Assistant prototype

Accessible, typing-first prototype for Holland Africa Research and Development. Open dist/index.html or serve the dist directory with any static HTTP server.

Includes sample cross-location search, a three-item proposal review with reversible edits, printable sample PDF preparation, recipient typo detection, gated practice submission, adjustable text, browser-dependent optional dictation and read-aloud.

All documents, contacts and addresses are fictional. No Gmail, Outlook, OneDrive, local folder indexing, AI review, real email sending, bounce monitoring or automatic Word conversion is connected. State is temporary and resets when the page reloads. PDF saving uses the browser print dialog; preparing a preview does not verify a PDF was saved. The proposal review is a scripted demonstration, not a real document analysis.

Next implementation: Windows file access and OneDrive identity/deduplication; Gmail OAuth and verified contacts; Word conversion with rendered output inspection; explicit approval gates; durable task and submission history; delivery failure monitoring. Outlook integration follows Gmail. Preserve originals and never infer delivery from a sent status.
